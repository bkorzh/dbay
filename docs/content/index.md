Device bay (or short DBay) is an open-source modular system for electronics used with superconducting nanowire single-photon detectors (SNSPDs).

Looking for an easy setup with minimal customization? Get the latest DBay software here: https://github.com/bkorzh/dbay/releases 

Developing the GUI, backend, or Python client? [[Start Here]] takes a fresh machine to a running development environment; the rest of the Development section covers the [[Repository Tour|layout]], the [[Architecture]], [[Building and Packaging|builds and releases]], [[Adding a Module|adding a module]], and [[Troubleshooting]].

To explore available modules, go to the [[Summary|Modules Summary]].
